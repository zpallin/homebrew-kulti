# homebrew-kulti

Homebrew tap for [kulti](https://gitlab.com/zpallin/kulti) — a CLI tool for creating and managing local k3s Kubernetes clusters.

## Install

```sh
brew tap zpallin/kulti
brew install kulti
```

## Usage

```sh
kulti create <name>          # create a k3s cluster
kulti list                   # list clusters
kulti delete <name>          # delete a cluster
kulti --help                 # full command reference
```

## Source
